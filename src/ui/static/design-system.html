Tokens and components used across Open Assistant. Everything here is built from css/tokens.css and css/components.css.

Colour

A soft, slightly warm neutral scale carries the whole interface. Green, orange and red appear only for meaning, and always as gentle tints with a readable foreground.

Typography

Inter, self-hosted, with a single-storey a and a tailed l for a friendlier, more legible texture. Body text is 15px; chat is 16px. Inline identifiers stay in Inter; Geist Mono is reserved for real code (code blocks, logs, JSON).

Icons

Every icon is from Lucide, served from one inline sprite in js/components.js. Use icon('name') in JS or <svg class="icon"><use href="#icon-name"> in HTML. Icons inherit the text colour.

Buttons

One primary action per area. Secondary for everything else, ghost for low-emphasis actions. Delete and remove are always a shaded red trash button; the solid red button is only for confirming a destructive dialog. Icon buttons are square, and button groups are right-aligned.

States

Do use the shaded red trash button (trashButton()) for delete and remove.

Don't use the solid red button outside a confirm dialog, or a text "Delete" button.

Do confirm destructive actions with modal.ask(), a solid red confirm and a label that says what happens.

Don't use window.confirm() or vague labels like "OK".

Badges & alerts

Status is always communicated with text as well as colour. Colour means an outcome (connected, failed, expiring); states such as enabled or public use the neutral .badge-on / .badge-off. For job and run statuses use statusBadgeClass(status).

Branding

The baseline is fully monochrome. An installation can add a brand accent by setting two variables, --brand and --brand-contrast; hover, tints and focus rings follow automatically. If the brand is too dark for the dark theme, add --brand-dark and --brand-dark-contrast. Try it:

On badge 
:root {
    --brand: #3b5bdb;          /* your accent */
    --brand-contrast: #ffffff; /* text on top of it */

    /* optional: a lighter variant for the dark theme */
    --brand-dark: #91a7ff;
    --brand-dark-contrast: #121211;
}
